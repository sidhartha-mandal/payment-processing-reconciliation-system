# Enterprise Payment Processing & Reconciliation System

A Java Spring Boot backend project that simulates enterprise-level payment processing, refund management, ledger tracking, and financial reconciliation.

## Project Overview

This project aims to demonstrate how a payment processing system handles transactions, prevents duplicate payments, maintains financial records, and identifies discrepancies between internal transaction records and external settlement data.

The system uses a simulated payment provider. No real money or banking transactions are involved.

## Key Features

- Customer Management
- Authentication and Role-Based Access Control
- Payment Processing and Status Tracking
- Refund Management
- Idempotency and Duplicate Payment Prevention
- Double-Entry Ledger Management
- Automated Payment Reconciliation
- Discrepancy and Exception Management
- Administrative Reports

## Technology Stack

- **Language:** Java 21
- **Backend:** Spring Boot
- **Database:** MySQL
- **ORM:** Spring Data JPA / Hibernate
- **Security:** Spring Security and JWT
- **Build Tool:** Maven
- **API Documentation:** Swagger / OpenAPI
- **Testing:** JUnit 5 and Mockito
- **Version Control:** Git and GitHub

## Architecture

The application follows a **Modular Monolithic Architecture** with a layered design.
